PRACTICAL 3 — MESSAGE AUTHENTICATION CODES / HASHING
Run: python main.py
Uses Python standard library only; no installation required.
The journal demonstrates MD5 and SHA-1 hashes. Since a plain hash is not a MAC,
this runnable version also demonstrates an actual HMAC-SHA256 tag and verification.
MD5 and SHA-1 are included only to match the journal exercise, not for security-sensitive use.
