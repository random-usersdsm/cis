PRACTICAL 8 — FIREWALL CONFIGURATION AND RULE-BASED FILTERING
This is a Windows Defender Firewall GUI practical in the journal (pages 19–27).
No script is run automatically because firewall changes can disrupt network access.

Steps:
1. Open Windows Security / Windows Defender Firewall.
2. Open Advanced settings.
3. Select Inbound Rules > New Rule.
4. Choose Port, select TCP, and enter the port specified by your instructor.
5. Select Block the connection; apply required profiles.
6. Give the rule a clear name and finish.
7. Repeat under Outbound Rules only if required by the practical.
8. To block a website, resolve its IP first and create a scoped rule as shown in pages 24–27.
9. Test access, then remove/disable the test rules to restore normal connectivity.

Use a lab/test machine and instructor-approved target/port. Avoid blocking broad ports or
changing firewall settings on a managed college/work computer without permission.
